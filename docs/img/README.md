# Portfolio screenshot checklist

Add real screenshots of the deployed site to this folder with the following filenames:

| File | What to capture |
|---|---|
| `home-dark.webp` | Hero / IDE shell in dark mode |
| `home-light.webp` | Hero / IDE shell in light mode |
| `projects.webp` | Search, filters, stack explorer, and project cards |
| `project-detail.webp` | A project case study + README detail view |
| `project-gallery.webp` | Repository image gallery / lightbox |
| `context-menu.webp` | Custom right-click context menu |
| `command-palette.webp` | `Ctrl/Cmd + K` Command Palette |
| `terminal-neofetch.webp` | Terminal after running `neofetch` |
| `mobile.webp` | Responsive mobile layout |

Suggested export settings:

- desktop screenshots: 1440 px wide
- mobile screenshot: 390 px wide
- WebP quality: 80-85%
- crop browser chrome unless it adds useful context
- avoid exposing private tabs, bookmarks, account avatars, tokens, or developer-console secrets

The root README already uses `public/og-cover-social.jpg`, so it never shows a broken screenshot while this folder is still empty.

## README wiring

The repository root `README.md` contains a copy/paste-ready Markdown gallery using these exact filenames. Once the screenshots are present, use that snippet to publish the gallery without renaming anything.
